# Exploring Group Theory Concepts Using Abacus Embeddings

By Colton Koenig, Levi Sprung

This repository contains the code we used for our work. It is a fork of the [Abacus Embeddings repository](https://github.com/mcleish7/arithmetic/), to which we added some features and functionality to attempt to explore commutativity and distributivity on a model trained with Abacus Embeddings.
